# ⚡ Black Firefox

> **The Dark Browser — Fast. Private. Secure.**  
> A premium, glassmorphic desktop browser built with Electron & Chromium, tailored for power users.

---

## 🎨 Features & Aesthetic

- **Glassmorphism Design System**: Translucent frosted panels (`backdrop-filter: blur(24px)`), smooth CSS micro-animations, and GPU-accelerated rendering.
- **Glass New Tab Page**: Integrated digital clock, weather, customizable search, speed dial grid, dock, and dynamic canvas background.
- **Collapsible Sidebar Rail**: Quick access to Bookmarks, Browsing History, Downloads, Quick Notes, and AI Assistant.
- **Tab Management**:
  - HTML5 Drag-and-Drop Tab Reordering
  - Pinned Tabs with favicon-only indicator
  - Automatic Tab Sleeping (suspends inactive tabs after 5 minutes to conserve RAM)
  - Quick Tab Search (`Ctrl+Shift+A`)
- **Media Suite**:
  - Picture-in-Picture mode (`picture_in_picture_alt`)
  - One-click Tab Muting
  - Media Session HUD
- **Privacy & Security**: Built-in ad-blocking, HTTPS enforcement, script toggles, and master-password protected Password Manager.

## 🚀 Quick Start

### Installation & Run

```bash
# Clone the repository
git clone https://github.com/shivamkumarmehta64-sketch/Black.git
cd Black

# Install dependencies
npm install

# Start development build
npm start
```
